All four RTX-3050 retention items from `tests/test_full_pipeline.py` are closed.

## Fixes landed during validation

- `d1adebb tk-005 fix: talker device + batch-dim contract for real CUDA weights`
  - run device now resolves from the *talker parameters*, not the CPU bridge
    (`extract_bridge_states` returns CPU); bridge is moved to the talker device.
  - `talker.forward` adds a batch dim for the vendored `MiniMindBlock`
    (expects `[B,T,H]`) and drops it again to keep the public 2D->2D contract.

## Bench re-measurement (`bench time`, RTX 3050)

`python -m nanovllm_omni.optim.bench time` measures the thinker decode
primitive (`run_generate`) over the six bench prompts:

| Path | runs | total median range (ms) | frames | VRAM |
|---|---|---|---|---|
| `--use-cuda-graph` | 20/prompt | **173–182** | 16 | ~1180 MiB |
| eager (default) | 10/prompt | **457–553** | 8 | ~615 MiB |

Prior README figures (~320 ms graph / ~715 ms eager) were measured on
torch 2.13.0+cu130; the improvement here is dominated by the torch upgrade,
not by retiring the collapsed pipeline (the bench primitive is unchanged).
